# Features Requiring External Credentials or Subscriptions

| Feature | Provider | Required config | Without it |
|---|---|---|---|
| Live calendar availability + events | Google Calendar API | `GOOGLE_SERVICE_ACCOUNT_JSON`, `GOOGLE_CALENDAR_ID` | Demo Mode: availability from the local schedule only, banner-labeled |
| Appointment register + reports | Google Sheets API | `GOOGLE_SERVICE_ACCOUNT_JSON`, `GOOGLE_SHEETS_SPREADSHEET_ID` | Register sync marked `not_configured`; bookings still work |
| Email confirmations/reminders | Any SMTP server (Gmail, SendGrid, Postmark…) | `SMTP_HOST/PORT/USER/PASS/FROM` | Messages logged server-side, marked demo |
| SMS reminders | Twilio | `TWILIO_ACCOUNT_SID/AUTH_TOKEN/FROM_NUMBER`, `SMS_NOTIFICATIONS_ENABLED=true` | SMS disabled |
| Realistic video avatar + lip-sync | HeyGen **or** D-ID | `AVATAR_PROVIDER=heygen\|did` + API key | Local demo avatar (animated SVG + browser voice) |
| Online consult links | Google Meet (free), Jitsi (free), Zoom (`ZOOM_API_KEY/SECRET`), or `CUSTOM_MEETING_URL_TEMPLATE` | `CONSULTATION_PLATFORM` | Links attached by staff in Admin |

**No credentials are required to run or demo the site.** Every unconfigured integration
degrades to a clearly-labeled Demo Mode and never pretends to be live.

## Free tiers worth noting

- Google Workspace service accounts: free with any Google account (Calendar API quota ~1M requests/day).
- Jitsi Meet: self-hosted or public meet.jit.si — free, no key.
- Google Meet: links can be generated by staff with a Google Workspace account.
- SMTP: Gmail SMTP works with an app password; Postmark/SendGrid free tiers cover clinic volume.
